🔄 Process Breakdown

How It Works

Four structured steps powering the StyleFind AI inference engine.

1

Upload

The user uploads an apparel photograph, takes a picture, or chooses an unseen test sample from the Fashion-MNIST test split.

JPG • PNG • WEBP
2

Preprocess

Applies auto-contrast, checks image edge polarity to invert bright backgrounds, and applies aspect-ratio padding to 28×28 pixels.

28×28 Grayscale
3

Analyze

Pixel values are scaled [0, 1] via MinMaxScaler and transformed into 50 orthogonal components using PCA dimensionality reduction.

MinMaxScaler + PCA(50)
4

Predict

The tuned Random Forest classifier computes category probabilities, and k-NN fetches the 5 closest items from the 10,000-item catalog.

Confidence & Nearest 5
⚙️ Technical Verification

Powered by Machine Learning

Verified architecture, benchmarking metrics, and confusion matrix from the training pipeline.

📦 Dataset
Fashion-MNIST (Zalando Research)

70,000 images (60,000 train, 10,000 test) across 10 balanced classes: T-shirt, Trouser, Pullover, Dress, Coat, Sandal, Shirt, Sneaker, Bag, Ankle boot.

🔄 Preprocessing Pipeline
MinMaxScaler → PCA(50)

Raw 0-255 pixels scaled to [0, 1] followed by Principal Component Analysis reducing 784 dimensions to 50 orthogonal components while retaining maximum variance.

🤖 Winning Algorithm
Random Forest (Tuned)

Winner selected via 3-Fold Stratified Cross-Validation macro F1 score. Best Hyperparameters: n_estimators: 100, max_depth: 20.

🎯 Model Accuracy
84.8% Test Accuracy

Tested on 10,000 unseen test samples. Macro F1: 0.847 • CV Macro F1: 0.878 • Latency: 0.45s.
